# Kaymap 1.0.0

- Windows 10/11 x64용 포터블 키 매핑 프로그램
- 설치·재부팅·별도 런타임 없이 EXE 실행으로 적용
- 0.13의 키 매핑 유지, 버전 표시 및 사용·진단·개발 문서 정리

## 주요 기능

- Alt → Windows Win → Mac Command 예상 매핑, 좌우 Alt 각각 적용
- CapsLock → Windows Ctrl → Mac Control 예상 매핑, HHKB On에서 적용
- Win → Windows Alt → Mac Option 예상 매핑
- HHKB 기본 활성화: Ctrl → CapsLock, Backspace ↔ 역슬래시 교환
- 일시정지·재개·입력 다시 연결·Windows 전송 진단 제공
- 일반 문자 입력 기록·파일 저장·네트워크 전송 없음

## 사용 방법

- 기존 Kaymap 종료 후 모든 키를 뗀 상태에서 새 EXE 실행
- 창 제목 `Kaymap 1.0.0 — Parsec 매핑 ON` 확인
- CapsLock → Control 사용 시 HHKB 모드 활성화 유지
- 기존 Parsec 설정 유지 후 실제 Mac 입력 확인
- EXE 단독 실행 또는 ZIP 압축 해제 후 실행
- [사용 안내](https://github.com/dylan-kwon/kaymap-win-to-mac/blob/1.0.0/README.md)

## 배포 파일 및 검증

- `kaymap-windows-x64.exe`: Windows x64 실행 파일
- `kaymap-windows-x64.zip`: 실행 파일·빠른 시작 안내·Go 라이선스
- `SHA256SUMS.txt`: EXE 및 ZIP의 SHA-256 체크섬
- 자동 테스트: 키 누름·해제·조합·반복 입력·일시정지·HHKB 전환·입력 정리·전송 실패·직렬화·진단 검증
- 배포 검증: race 검사 포함 전체 테스트·Windows 대상 vet·x64 빌드·ZIP 무결성 확인
- 실제 Windows Hook·Parsec·Mac 앱을 통한 1.0.0 수신은 자동 검증 범위 외, 실기 확인 필요
- Mac 입력은 Parsec 설정에 따라 달라질 수 있음
